# SupplyChainIQ

## Intelligent Supply Chain Analytics & Optimization Platform

An end-to-end data analytics project focused on understanding,
analyzing and optimizing supply chain operations.

### Objectives
- Analyze supply chain performance.
- Identify inventory and delivery inefficiencies.
- Evaluate supplier and logistics performance.
- Forecast product demand.
- Predict stockout risks.
- Generate actionable business recommendations.

### Technology Stack
- Python
- Pandas and NumPy
- SQL and PostgreSQL
- Excel
- Power BI and DAX
- Statistics
- Scikit-learn
- FastAPI
- Generative AI and LLMs

### Dataset
DataCo Smart Supply Chain Dataset

Source:
https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis
